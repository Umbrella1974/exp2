============================================================
三、新增 session_recorder.py
============================================================

新增模块 session_recorder.py。

功能：
提供 SessionRecorder，用于在实验或离线 replay 中保存完整 session 数据。

推荐 session 目录结构：

session_dir/
  session_meta.json
  calibration.json
  trial_config.json
  raw_frames.jsonl
  device_frames.jsonl
  processed_frames.csv
  events.csv
  haptic.csv
  trial_summary.json
  plots/

SessionRecorder API 建议：

class SessionRecorder:
    def __init__(self, session_dir: str | Path, overwrite: bool = False)

    def __enter__(self) -> "SessionRecorder"
    def __exit__(...)

    def start_session(
        self,
        session_meta: dict,
        calibration: dict | None = None,
        trial_config: dict | None = None,
    ) -> None

    def record_raw_frame(self, frame_index: int, raw_frame: dict) -> None

    def record_device_frame(self, frame_index: int, device_frame) -> None

    def record_processed_frame(
        self,
        frame_index: int,
        raw_frame: dict | None,
        device_frame,
        sample,
        frame_output,
        haptic_state=None,
        extra: dict | None = None,
    ) -> None

    def record_events(self, frame_index: int, time: float | None, events) -> None

    def record_haptic(
        self,
        frame_index: int,
        time: float | None,
        haptic_state,
        haptic_command=None,
        details: dict | None = None,
    ) -> None

    def finalize(self, summary: dict) -> None

设计要求：
- 使用标准库 csv/json/pathlib/datetime
- 尽量不要引入新依赖
- 支持 context manager
- 写 CSV 时使用固定 header
- 对 dataclass / enum / numpy-like 数值做安全序列化
- None 写成空值或 JSON null，不要崩溃
- recorder 不应改变实验状态，只做观察和落盘
- raw_frames.jsonl 必须尽量原样保存 raw dict，不要改写 raw frame 字段
- device_frames.jsonl 保存 DeviceFrame 摘要，不要重复保存完整 raw

1. raw_frames.jsonl 必须严格保存原始 raw dict。
   record_raw_frame(frame_index, raw_frame) 中的 frame_index 只用于 recorder 内部定位，不得写入 raw_frames.jsonl，不得修改 raw_frame。
