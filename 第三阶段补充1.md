二、新增模块：raw_frame_source.py
============================================================

请新增 raw_frame_source.py，定义统一的 raw frame source 接口。

建议结构：

class RawFrameSource:
    def __iter__(self):
        return self

    def __next__(self) -> dict:
        raise NotImplementedError

或者：

class RawFrameSource:
    def next_frame(self) -> dict | None:
        raise NotImplementedError

实现两个 source：

1. JsonlRawFrameSource

用途：
- 从 .jsonl 文件读取 fake 或录制 raw frame。
- 每一行是一个 raw JSON dict。
- 用于 pytest、offline replay、debug。

要求：
- 支持 path: str | Path
- 跳过空行
- 如果某行 JSON 无效，抛出清晰 ValueError，包含行号
- 不依赖真实设备

2. IterableRawFrameSource

用途：
- 接收 list[dict] 或 iterable[dict]
- 用于单元测试

要求：
- 每次返回一个 raw dict
- 不修改输入 dict

可选预留：

3. ManusSocketRawFrameSource

第一版只写接口 / TODO，不要求完整接入真实 socket。
如果实现，要求：
- 只负责产出 raw dict
- 不参与 parser / adapter / trial 逻辑
- 不 import manus_vive_com 的 demo / calibration 逻辑
- 如果需要外部 receiver，应该通过依赖注入传入 callable，例如 receiver.get_latest_raw_frame()

可以写成：

class ManusSocketRawFrameSource:
    def __init__(self, receiver):
        self.receiver = receiver

    def next_frame(self):
        # TODO: adapt actual receiver output to raw dict
        ...

六、关于真实 manus_vive_com 的接入边界
============================================================

请不要在本阶段强行 import manus_vive_com。

如果要预留接口，只做很薄的一层：

RawFrameSource 只负责返回 raw dict。
raw dict 应该大致满足：

{
  "timestamp": ...,
  "frame": ...,
  "skeletons": [
    {
      "gloveId": "...",
      "nodes": [
        {"id": 0, "position": [x, y, z], "rotation": [x, y, z, w]},
        ...
      ]
    }
  ],
  "trackers": [
    {
      "id": 0,
      "trackerId": "...",
      "position": [x, y, z],
      "rotation": [x, y, z, w],
      "quality": ...,
      "valid": true
    }
  ]
}

但是 parser 必须容忍：
- skeletons 缺失
- trackers 缺失
- nodes 缺失
- position 缺失或非法
- tracker.valid=false
- 额外字段

七、DeviceAdapterConfig 小要求
============================================================

这是 Stage 3 初版简化模型，不代表最终 MANUS/Vive 空间融合精度。
