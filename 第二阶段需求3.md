这两个点确认：

1. trial_id 由外部传入。
   API 使用 start_trial(time: float, trial_id: int | str)。
   TrialController 不自己生成 trial_id。
   所有 TrialFrameResult、EventRecord、frames.csv、events.csv 都使用外部传入的 trial_id。

2. Stage 2 第一版 tracking invalid 不切换 TrialState。
   TrialState 在 tracking invalid 期间保持 RUNNING。
   TrialController 只在 valid -> invalid 时记录 tracking_invalid event，在 invalid -> valid 时记录 tracking_recovered event。
   BlockController 继续负责 invalid / recovery 的实际处理。
   TrialState.TRACKING_INVALID 如果保留，只作为 reserved/future use，不在第一版实际进入。
