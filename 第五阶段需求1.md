一、新增 calibration_io.py
============================================================

新增模块：
calibration_io.py

实现数据结构：

1. CalibrationPointRecord

用于记录 origin 静止采样结果。

字段：
- label: str，例如 "origin"
- point_world: list[float] length 3
- source: str，例如 "pinch_center_world" / "tracker_position_world"
- frame_start: int | None
- frame_end: int | None
- sample_time_start: float | None
- sample_time_end: float | None
- duration_seconds: float | None
- sample_count: int
- mean_world: list[float] length 3
- std_world: list[float] length 3
- max_deviation_m: float | None
- metadata: dict

说明：
point_world 通常等于 mean_world。
保留 point_world 是为了之后读取更方便。

2. CalibrationLineRecord

用于记录长边线 / 宽边线 / 对角线采样结果。

字段：
- label: str，例如 "long_axis_line" / "width_axis_line" / "diagonal_line"
- source: str，例如 "pinch_center_world" / "tracker_position_world"
- frame_start: int | None
- frame_end: int | None
- sample_time_start: float | None
- sample_time_end: float | None
- duration_seconds: float | None
- sample_count: int
- points_world: list[list[float]] 可选；如果担心文件太大，可以只保存抽样或不保存全量，但至少保留 fit 结果
- centroid_world: list[float] length 3
- direction_world: list[float] length 3
- line_fit_rmse_m: float | None
- line_length_m: float | None
- endpoint_min_world: list[float] length 3 | None
- endpoint_max_world: list[float] length 3 | None
- metadata: dict

3. PlaneFitRecord

字段：
- normal_world: list[float] length 3
- centroid_world: list[float] length 3
- plane_fit_rmse_m: float | None
- sample_count: int
- source_labels: list[str]
- metadata: dict

4. FormalCalibration

字段：
- calibration_id: str
- created_at: str
- calibration_type: "formal_table_lines"
- is_formal_calibration: true
- coordinate_space: "world_to_task"
- unit: "m"
- point_source: str
- origin: CalibrationPointRecord
- long_axis_line: CalibrationLineRecord
- width_axis_line: CalibrationLineRecord
- diagonal_line: CalibrationLineRecord
- plane_fit: PlaneFitRecord
- origin_world: list[float] length 3
- x_axis_world: list[float] length 3
- y_axis_world: list[float] length 3
- up_axis_world: list[float] length 3
- task_coordinate_system: dict
- quality: dict
- warnings: list[str]
- metadata: dict

说明：
- long_axis_line 主要用于确定 x_axis_world
- width_axis_line 用于确定 y 方向和正交性检查
- diagonal_line 主要用于质量检查
- plane_fit 用三条线的采样点一起拟合桌面平面
- x_axis_world 应该由 long_axis_line.direction_world 投影到 plane 上得到
- y_axis_world 应该由 up_axis_world 与 x_axis_world 正交构造得到，而不是直接完全相信 width line

5. CalibrationValidationResult

字段：
- errors: list[str]
- warnings: list[str]
- is_valid property

实现函数：
- save_calibration(calibration: FormalCalibration, path) -> None
- load_calibration(path) -> FormalCalibration
- validate_calibration(calibration) -> CalibrationValidationResult
- build_task_coordinate_system_from_calibration(calibration) -> TaskCoordinateSystem
- calibration_to_dict(calibration) -> dict
- calibration_from_dict(payload) -> FormalCalibration

要求：
- 使用标准库 json/pathlib/datetime/dataclasses
- 可使用 numpy 做线拟合和平面拟合；如果项目已有 numpy 依赖，可以直接使用
- JSON pretty-format，2 空格缩进
- 字段稳定，便于手工查看
- 不依赖真实设备
- 不依赖 manus_vive_com

二、新增 calibration_geometry.py
============================================================

新增模块：
calibration_geometry.py

实现几何工具函数：

1. fit_line_3d(points) -> dict

输入：
- list[list[float]]

输出：
- centroid
- direction
- rmse
- line_length
- endpoint_min
- endpoint_max

建议实现：
- 使用 PCA/SVD 拟合 3D 直线
- direction 使用第一主成分
- line_length 使用点投影到主方向后的 max-min
- rmse 使用点到拟合线的均方根距离

2. fit_plane_3d(points) -> dict

输入：
- 多个 3D 点

输出：
- centroid
- normal
- rmse

建议实现：
- 使用 PCA/SVD 拟合平面
- normal 使用最小特征方向
- normal 方向可后续根据 up_hint 调整

3. project_vector_to_plane(vector, plane_normal) -> list[float]

4. normalize_vector(vector) -> list[float]

5. angle_degrees(a, b) -> float

6. choose_up_direction(plane_normal, up_hint) -> list[float]

说明：
- 如果 plane_normal 与 up_hint 点积为负，翻转 plane_normal
- up_hint 默认 [0,0,1]

7. build_axes_from_table_lines(origin, long_line, width_line, diagonal_line, up_hint) -> dict

行为：
- 用三条线所有采样点拟合 plane normal，得到 up_axis_world
- 将 long_line.direction_world 投影到平面上，得到 x_axis_world
- 如果 x_axis_world 太短，报 error
- 使用 y_axis_world = normalize(cross(up_axis_world, x_axis_world))
- 如果 width_line.direction_world 与 y_axis_world 方向相反，可以只用于误差检查，不强行翻转 y_axis
- 对 diagonal_line 做质量检查：
  - 如果长宽比例未知，检查 diagonal line 是否大致在 x/y 平面内
  - 如果可估计长宽长度，则检查 diagonal 方向是否接近 normalize(x_axis * long_length + y_axis * width_length)
  - 第一版可以只检查 diagonal line 与 plane 的一致性，以及它与 x/y 轴都不是过近 0° 或 90°

输出：
- origin_world
- x_axis_world
- y_axis_world
- up_axis_world
- plane_fit
- quality metrics
- warnings

注意：
不要修改 TaskCoordinateSystem。
最终仍通过 TaskCoordinateSystem.build_from_origin_and_x_point 构造 task coordinate system，其中：
- origin_world = origin point mean
- x_point_world = origin_world + x_axis_world
- up_axis_world = plane normal

三、calibration 质量检查
============================================================

validate_calibration 至少检查：

基础字段：
- calibration_type == "formal_table_lines"
- is_formal_calibration == true
- origin_world / x_axis_world / y_axis_world / up_axis_world 都是 finite 3D
- x_axis_world / y_axis_world / up_axis_world 都接近单位向量
- x/y/up 互相接近正交

采样质量：
- origin.sample_count >= min_samples，默认 10
- long_axis_line.sample_count >= min_samples，默认 10
- width_axis_line.sample_count >= min_samples，默认 10
- diagonal_line.sample_count >= min_samples，默认 10
- 每段采样 duration_seconds 接近 5 秒；如果低于 3 秒，warning；低于 1 秒，error
- line_length_m >= min_line_length，默认 0.10 m
- plane_fit_rmse_m 如果太大，warning
- line_fit_rmse_m 如果太大，warning
- origin.max_deviation_m 如果太大，warning
- long_axis 与 width_axis 夹角应接近 90°，偏差过大 warning 或 error
- diagonal_line 应在拟合平面内，偏差过大 warning

quality 中至少保存：
- plane_fit_rmse_m
- origin_sample_count
- long_line_sample_count
- width_line_sample_count
- diagonal_line_sample_count
- origin_max_deviation_m
- origin_std_world
- long_line_fit_rmse_m
- width_line_fit_rmse_m
- diagonal_line_fit_rmse_m
- long_line_length_m
- width_line_length_m
- diagonal_line_length_m
- x_y_angle_degrees
- x_up_angle_degrees
- y_up_angle_degrees
- diagonal_plane_rmse_m 或 diagonal_line_fit_rmse_m
- calibration_quality_status: "ok" / "warning" / "error"

不要因为 warning 阻止保存 calibration。
但 formal replay 使用时，如果 validation.errors 非空，应失败。

五、新增 calibrate_from_raw_jsonl_table.py
============================================================

新增脚本：
calibrate_from_raw_jsonl_table.py

目标：
用已有 raw JSONL 模拟正式“桌面三线标定”流程，测试 calibration 文件格式和质量检查。

注意：
这个脚本不是 live calibration，只是从 raw JSONL 中按帧段截取数据来模拟：
- origin 静止 5 秒
- 长边线移动 5 秒
- 宽边线移动 5 秒
- 对角线移动 5 秒

输入参数：
- --raw-jsonl path，必填
- --out path，默认 data/calibration/table_line_calibration.json
- --calibration-id 可选
- --origin-start-frame int，必填
- --long-line-start-frame int，必填
- --width-line-start-frame int，必填
- --diagonal-line-start-frame int，必填
- --sample-duration-seconds 默认 5.0
- --sample-window-frames 可选，如果提供则优先使用帧数；否则按 sample_duration_seconds 尽量根据 sample_time/raw timestamp 取 5 秒
- --point-source tracker_position_world / pinch_center_world，默认 tracker_position_world
- --thumb-node 默认 4
- --index-node 默认 9
- --tracker-index 默认 0
- --skeleton-index 默认 0
- --up-hint 默认 "0,0,1"
- --min-samples 默认 10
- --min-line-length 默认 0.10
- --notes 可选

行为：
1. 读取 raw JSONL。
2. 每帧 parse_raw_manus_vive_frame。
3. 每帧用 ManusViveExperimentAdapter 得到 ExperimentInputSample。
4. 根据四个 start frame 提取四段采样：
   - origin segment
   - long line segment
   - width line segment
   - diagonal line segment
5. 每段默认按 sample_duration_seconds 采集 5 秒。
6. 如果无法可靠用时间取窗口，则 fallback 到 sample-window-frames；如果也没有则报错提示用户指定 --sample-window-frames。
7. origin segment 做静止点平均。
8. 三条 line segment 做 line fit。
9. 三条线所有点做 plane fit。
10. 构造 FormalCalibration。
11. validate_calibration。
12. 如果 validation.errors 非空，清晰失败。
13. 保存 calibration.json。
14. 打印 quality summary。

输出 calibration.json 中 metadata 必须包含：
- source = "raw_jsonl_simulated_table_line_calibration"
- sample_duration_seconds
- point_source
- raw_jsonl path
- warning:
  "This calibration was created from replayed raw JSONL for testing the calibration format; live formal calibration should collect points interactively."
